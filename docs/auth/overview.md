# Overview

Eventually, this project aims to support the same set of authentication providers like the upstream [Supabase Auth](https://supabase.com/docs/guides/auth).

Due to the fact, that this is currently still a PoC, the list of supported providers is still rather short.

You can either configure [email auth](email.md) or use one of the supported social providers:

- [Azure](providers/azure.md)
- [GitHub](providers/github.md)
